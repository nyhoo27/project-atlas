# Roadmap

## V1 (current)

The modules described in [product-requirements.md](product-requirements.md):

- Authentication (signup + login, workspace created on signup)
- Customers
- Items
- Interactions (append-only, with atomic follow-up task creation)
- Tasks
- Settings (configurable options + tags)
- Dashboard
- Activity Log
- Basic Search
- Basic Role Support

## V1.5

- File attachments (Supabase Storage)
- Better timeline UI (richer grouping/filtering of activity)
- Better search (beyond simple `ilike` — maybe Postgres full-text search)
- More granular permissions

## V2

- Sales (converting an item + customer into a recorded sale)
- Payments
- Expenses
- Reports

## V3

- Custom fields (per-workspace, per-module)
- Document management
- Notifications

## V4

- Automation / workflow builder
- AI assistant
- External integrations (WhatsApp, email, etc.)
